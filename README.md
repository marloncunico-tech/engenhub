# Engenhub – site (Linha C · Zirconium)

Site estático de página única: consultoria Aras Innovator, implantação de Dolibarr, EspoCRM e OpenProject, BI, IA e infraestrutura em nuvem gerenciada.

## Publicar no GitHub Pages
1. Crie um repositório (ex.: `engenhub-site`) e envie `index.html`, `.nojekyll` e este README para a raiz.
2. Em **Settings › Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. Domínio próprio (opcional): crie um arquivo `CNAME` com `engenhub.com.br` e aponte o DNS para o GitHub Pages.

## Formulário
Envia para **contato@zirconiumlabs.com** via FormSubmit (POST multipart; anexos compactados num único .zip, limite de 10 MB).
No primeiro envio a partir do domínio publicado, o FormSubmit manda um e-mail de ativação para esse endereço: clique em *Activate*.

## Conteúdo
- Imagens das plataformas embutidas em base64, obtidas dos sites oficiais (aras.com, dolibarr.org, espocrm.com, openproject.org), com crédito na legenda. As marcas pertencem aos seus titulares.
- Preços e simulador seguem a tabela da Linha C (plano de negócios). Para alterar valores, edite a seção `simulador` no script do `index.html`.
